# wechat-viral-article

根据一句话、一个想法、一个热点或一个痛点，生成一篇可直接发布的微信公众号爆文。

## 给 Agent 用

把本仓库的 `SKILL.md` 作为 skill 说明读入，即可按流程工作。输入只需要一句话或一个想法，不需要大纲。

## 一次交付什么

1. 标题 10 个，分组并标 1 个首选和理由
2. 摘要 1 段（不超过 120 字）
3. 正文全文（1600 至 2200 字，带 01、02、03 小标题和结尾金句）
4. 封面图 1 张（横版约 900×500）
5. 文章配图 3 张（开头后、第 2 个案例后、结尾前）

## 写作范式

来自 2026-10-28 对洞见、雾满拦江、李月亮的精读（共 60 篇）：

- 道理、感悟 → 洞见式：3 至 5 个案例，历史名人加身边小事混用
- 热点、人名、新闻 → 李月亮式：热点开头，并列案例或单事件深挖
- 纠纷、防坑、远离某类人 → 雾满拦江社会篇式：1 主案加 1 类比
- 雾满拦江连载的悬念加未完待续结尾不适合单篇人生文，不用

口径限定：洞见 20 篇取自聚合页，无日期且混季节篇，只能作结构样本；雾满拦江要区分连载和社会篇；李月亮含转载，结构无明显区别。

## 使用说明

- 标题不超过 30 字，标题承诺的冲突正文里必须圆回来
- 结尾必须是一句能单独截图转发的话
- 没有来源的人名、事件、数据、名言不编，核实不了就改成化名小事
- 不承诺“一定爆”“必 10 万＋”
